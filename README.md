# Outrider's Outpost

[![Site](https://img.shields.io/badge/site-0utrider.github.io%2Foutpost-7000d6)](https://0utrider.github.io/outpost/)

The home of Outrider's Foundry VTT modules: a plain list of the modules, with links to each one's page.

Site: https://0utrider.github.io/outpost/

Browser tools for PF2e and SF2e (Ledge Line of Sight, Challenge Point and Downtime calculators) live at
https://0utrider.github.io/pathfinder/.

## Layout

- `site/`: the GitHub Pages site, deployed by `.github/workflows/pages.yml`.

An optional Foundry VTT module, a central settings manager for the Outrider modules, is planned and will ship from this
repo as a release zip. The site is never part of that zip.
